# Cursorへ渡す開始指示

先に`01_CURRENT`をCursorで開き、同フォルダで`setup_cursor.cmd --geometry`を実行します。
既存のプロジェクトへ導入して使う場合は、そのプロジェクトへ配置されたSkillを読みます。
以下をAgentチャットへ貼り付けてください。

```text
.cursor/skills/cadmcp-cursor/SKILL.mdを読み、導入したcadMCPの接続確認から始めてください。

brain_doctor、brain_fs_status、brain_studio_schema(name="FunctionBrief")を実際に呼んでください。
MCP接続、CADカーネル、Req2CAD注釈件数、CAD対応数、意味検索索引の状態を個別に報告してください。
全件データが未導入なら完了扱いせず、デモ4件や字句検索で黙って代替しないでください。

私が特に必要としているのは、機能から実例CADを検索し、その形状・面・接続構造を参考にして
内部機構を設計する能力です。要求管理と形式検査だけで終えないでください。
実際のシェル・PCB・スイッチが必要な段階では実ファイルから測定し、架空の寸法を確定しないでください。

設計では、必要機能→実例CAD検索→実形状と面の確認→複数の構造案→構築レシピ→実カーネル検査
→要求・機構・組立・製造・検証のレビュー→相互反証→固定条件での修正という順序で進めてください。
独立サブエージェントが利用できない場合は明示し、同一Agentの順番レビューを5モデル実行と称しないでください。

元のCAD正本、シェル、基板、既存MCP設定、認証情報を無断で変更しないでください。
外部CLIのモデル呼び出しや全件ダウンロードは、実行する処理・保存先を示して明示された範囲で行ってください。
APIキーをコードや配布ZIPへ保存しないでください。
実行済み、失敗、未検証を分け、未検証を合格と報告しないでください。
```
