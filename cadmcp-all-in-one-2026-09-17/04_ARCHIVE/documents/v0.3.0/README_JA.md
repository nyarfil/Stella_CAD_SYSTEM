# cadMCP Design Studio 0.3.0

## 何が変わったか

中心機能を「要求を記録する」から、**機能から実例CADを探し、実際の面・穴・接続構造を確認して、対象寸法へ適合させる**経路に拡張しました。Req2CADの少数手作り代替カードを増やす変更ではありません。

```text
雑な指示 → 原文付き機能要求 → 機能別の実例検索 → UID一致の実CAD
        → 内側の穴面／外側の軸面／支持面を実測
        → 機能ごとに複数案 → 適合する組み合わせ
        → 出典付きCADレシピ → STEP／STL／4方向PNG／面接続グラフ
        → 寸法・全出力ペア干渉・静止隙間・直線移動の検査
        → 5役の初回レビューと相互反証 → 条件を固定した修正 → 所有者レビュー
```

**実装した範囲と完成保証は区別します。** 本版は限定された操作集合を持つ試作設計システムです。任意の雑な要求から常に製造可能なマウスを完成させる保証、Req2CAD原版の完全再現、全件導入済み・全件検証済みDBではありません。

## 本版で実行確認した中核

| 段階 | 実装と確認 |
|---|---|
| 出典と実CAD | 公開ミラーの4件の元JSONをGit blob SHAとSHA-256で照合し、実カーネルでソリッドへ復元 |
| 機能検索 | 多対多の機能語↔UID、機能ごとの言い換えを同じ要求として集約。全CSV用取り込みとQwen索引処理を実装 |
| 構造の実測 | 面種類・面の隣接・円筒の内外・平面・方向・半径を取得。説明文ではなく引用した面が前提を満たすか検査 |
| 構想 | 機能別の複数実現案と不適合な組み合わせを列挙。検索ヒットの多さを強度や品質の点数にはしない |
| 形状生成 | 参照CAD、登録済みSTEP、箱、円筒、剛体変換、一様倍率、ブーリアン、指定Rのフィレットから実STEPを生成 |
| 検査 | B-rep妥当性、ソリッド数、寸法、全出力部品間の干渉、静止隙間、直線移動の適応サンプリング |
| 討論・修正 | 要求・機構・組立・製造・検証の5役。初回と相互反証を分離。修正で合格基準を緩めない |
| 実行基盤 | 33個のMCPツール、状態・根拠hash・世代管理、ローカル証拠ページ、所有者側CLIの実行回数・時間制限 |

意味検索の索引計算は制御用ベクトル、討論の接続は明示したスクリプト応答で試験しました。**実Qwen・実Codexの設計知能を評価したわけではありません。** 全試験260件の分類は `TEST_REPORT_JA.md` を参照してください。

## 今すぐ確かめられる実形状の例

`examples/public-cases/`に、Req2CAD公開機能語と共通UIDを持つ公開ミラーの元CAD4件を格納しました。元CADの一次配布アーカイブとの同一性は未照合、無作為標本でもありません。説明文は注釈の要約、機能語は公開値です。

`examples/real-reference-output/EVIDENCE_REVIEW.html`をブラウザーで開くと、実際に使った参照形状、加工後の案内部品と軸、全検査結果、未検証事項が見られます。HTMLはローカル読取専用、外部JS・通信・追跡・プリンタ送信なしです。

デモは、フランジ付きの実例CADと中実の軸の実例CADを加工した**ソフトウェア検証用レシピ**です。LLMが自由文から独力で完成した実例や、QIDI/ABSで確認した推奨寸法ではありません。元の実寸単位を推定せず、倍率と試作用の採用理由を記録しています。

再実行：

```powershell
.\setup.cmd --geometry
.\.venv\Scripts\python.exe scripts\demo_real_references.py --workspace .\demo-workspace
```

デモ用workspaceを本番DBと共用しないでください。新規またはデモ専用マーカーのあるフォルダ以外へ4件の小標本を上書きしない検査を入れています。

## 全件Req2CADの導入

```powershell
.\setup_req2cad.cmd --download-deepcad --reference-only
```

原CSV、原CADアーカイブ、Qwen3-Embedding-4Bの実重みを原配布元から取得し、注釈→UID→CADと機能語索引を構築します。**この作成環境では一括取得に失敗したため、全件での完走は未検証です。** 失敗時は欠損を報告し、デモや単語検索へ黙って切り替えません。`--csv`と`--cad-path`で正規に取得済みの原本を渡せます。圧縮された内側のCADアーカイブを安全に展開・索引化する処理も追加しました。

`--reference-only`では元座標を参考形状の座標として扱います。元の1単位を物理的な1mmと認定しません。全件のCAD復元を必須にせず、選ばれた候補から復元・キャッシュする方式です。

## 2つの動かし方

### A. 既存Cursor／Codex＋MCP

既存ホストモデルが推論し、MCPが検索・計測・状態管理を実行します。別の生成AI API呼び出しは行いません。生成したMCP設定の**追加項目のみ**を既存設定へマージし、同梱Skillを読ませてください。

### B. 所有者が明示起動する自動実行

所有者の端末で認証済みCodex CLIを使い、5役を別の実行コンテキストで呼び出すアダプターです。既定は初回レビュー＋相互反証の2巡、最大1回の修正、最大32回のモデル呼び出しです。件数・時間上限は安全な停止と費用管理のために残します。

```powershell
.\.venv\Scripts\python.exe -m cadmcp_brain.studio --workspace .\workspace autopilot --project mouse-design --request-file .\request.txt --execute-model --debate-rounds 2 --max-calls 32
```

独立したコンテキストは誤りの独立性を保証しません。ここで5人や5モデルによる実討論を実施したとはしていません。実CLIは所有者の版・認証・モデルで接続試験が必要です。CLIがない場合や出力契約が違う場合は推測して続行しません。MCPモードで無断に別モデルを起動しません。

## 守る対象

基板、スイッチ、センサー、レンズ等は実データを登録して位置・寸法・変更権限を明示します。`--protect-artifact PCB`は登録済みIDを固定したまま出力アセンブリに含める指定です。欠落・移動・形状変更を拒否します。編集可能なシェルは所有者が`--editable-reference shell`で許可します。モデルがレシピ中のroleを変更して権限を得ることはできません。

プロトタイプ出力は正本CADとは別ディレクトリに作ります。自動でCAD正本・MCP設定全体・プリンタを書き換えません。基準変更と設計変更は分離され、多数決やモデルの「合格」だけで検証結果を変えません。

## 明示して残る範囲

MCP通信は2025-06-18のstdio tools/resources/promptsの限定実装です。最新全仕様や全クライアント対応は主張しません。旧0.2.0の文書は`docs/archive`に隔離し、現在の結果に混ぜていません。

詳しくは `INSTALL_INTEGRATE_JA.md`、`AGENT_WORKFLOW_JA.md`、`docs/UPSTREAM_AUDIT_JA.md`、`docs/DESIGN_REVIEW_JA.md` を参照してください。
