# MCPツール一覧

生成元: cadmcp_brain.api.Tools.list()。正確な引数はschemas/mcp-tools.jsonまたはbrain_schema/brain_task。

| 名前 | 用途 |
|---|---|
| brain_add_source | Append an exact new user instruction; invalidate old intent, concepts, plans and verification, preserving audit history. |
| brain_backend_call | Opt-in gated AgentCAD call. Owner allowlist required. Default dry-run. A call_id permits at most one network write attempt; never retry uncertain outcomes. |
| brain_backend_probe | Read the configured loopback AgentCAD live tool registry. Disabled unless CADMCP_AGENTCAD_URL is set by the owner. |
| brain_doctor | Report local capabilities without pretending to test a remote CAD backend or a Windows/Cursor installation. |
| brain_export | Export immutable contract.json, CAD_HANDOFF.md and design_graph.json for the existing CAD backend. Does not execute CAD. |
| brain_fs_case | Read exact original functional annotation and linked asset metadata. Labels are hypotheses, not verified engineering capabilities. |
| brain_fs_compare | Compare actual materialized face-adjacency topology (WL) and surface geometry descriptors. Not a functional equivalence or automatic assembly proof. |
| brain_fs_evidence | Return source-hashed function + geometry + topology evidence, usable in Concept.case_references. Requires original file integrity; no strength claims. |
| brain_fs_interfaces | Inspect materialized planar/cylindrical surfaces. Distinguish inner cavity from solid shaft exterior; NOT proof of through-bore, fit, force transmission or fatigue. |
| brain_fs_materialize | Reconstruct/import the registered real CAD; export STEP/STL/views and measure face-type graph, WL features and sampled geometry. Never invent geometry for missing UIDs. |
| brain_fs_portfolio | Choose structurally diverse representatives from retrieved, measured CAD UIDs. Missing geometry is reported, not fabricated. |
| brain_fs_search | Retrieve real CAD UIDs by functional keywords. Semantic is default and requires a prepared real model/index. Lexical mode must be explicitly requested. mode=geometry_encoder ranks by the in-house CAD-construction encoder (annotations unused); explicit only, no fallback, may be experimental. |
| brain_fs_search_tasks | Search multiple paraphrases per functional requirement without double-counting them. Inspect real surface preconditions; unknown geometry is not a pass. Explicit lexical mode is only a diagnostic/limited retrieval route. |
| brain_fs_status | Read actual function/asset/geometry coverage. An empty catalog is not an installed 128k library. |
| brain_fusion_handoff | Issue the only Fusion adapter script allowed for this built subject. Host must pass it to fusion_mcp_execute unchanged. Does not save f3d. CadQuery remains the geometry referee. |
| brain_fusion_ingest | Accept Fusion print JSON only when it echoes the issued adapter. Remeasure overlap/clearance/motion in CadQuery. A Fusion screenshot is not a pass. f3d is not saved. |
| brain_get | Read current state and revision. Reload after REVISION_CONFLICT; never overwrite a newer design. |
| brain_history | Read the transactional project event history. |
| brain_import_step | Copy/hash a workspace-relative STEP. output needs current contract digest; reference performs actual kernel measurements and invalidates concepts/plans. Trusted local STEP only. |
| brain_mouse_build_shell_brep | Hollow a READY scan into an open-bottom solid. route faceted_sdf (default): signed-distance shell, surface nets, one planar face per triangle (voxel_mm, max_faces, max_voxels). route smooth_fit: two fitted B-spline surfaces (outer skin = scan, inner skin = phi=-thickness) on the same rays + a planar ring on the opening plane; needs a scan that is star-shaped from the opening-section centroid and locally thicker than 2 x thickness (grid default 121, max 201; degree_min, degree_max, fit_tolerance_mm, smoothing). Routes never fall back to each other; checks report PASS/FAIL/UNVERIFIED and stop codes replace coarsening or loosening. |
| brain_mouse_get_board_pack | Read one stored board pack. Presence is not printability, optical alignment, or click-feel. |
| brain_mouse_get_shell_pack | Read one stored shell pack. Registration is not printability, wall-thickness proof everywhere, or optical alignment. |
| brain_mouse_inspect_inputs | Hash workspace files and report board/shell pack status. A STEP on disk is not a ready shell. Does not invent fasteners or a passing design. |
| brain_mouse_list_board_packs | List draft and ready board packs in this workspace. Demo CAD cases are not listed here. |
| brain_mouse_list_shell_packs | List draft and ready prepared-shell packs. A mesh scan is not listed here. |
| brain_mouse_prepare_scan | Inspect a closed scan mesh (STL/OBJ) for scan-to-shell stage A1: unit (required, never guessed), topology, orientation, components, holes. Only allow-listed repairs run (all default off) and each is reported. Writes mouse/scans/<scan_id>/; READY or NOT_READY with reasons. Self-intersection stays UNVERIFIED. |
| brain_mouse_recognize_regions | Find left click, right click, scroll wheel, side button 1/2 and palm shell on a READY prepared scan (best on the full-resolution STL from brain_mouse_scan_model). Frame, front/rear, base and right/left-hand mouse are detected from the mesh; boundaries come from seam grooves plus calibrated mouse-shape priors. Per region: face ids (hashed npz), area, bbox, high/med/low confidence and a note for every inferred (non-groove) boundary stretch; optional top/flank overlay PNGs. NOT_READY for a mesh that is not welded/closed. Surface-only: hinges, switches and axle are not visible and not inferred. Calibrated on an OP1-class mouse. |
| brain_mouse_recognize_regions (R2.1) | Region version R2.1 (keys added only): click / wheel / palm boundaries follow the scan grooves as smooth 3-D curves (groove-penalised growth from region interiors, groove ridge traced across each boundary, faces by side of the curve); stretches without a groove are inferred and listed. New per-region `boundary_3d` (length, groove_followed_fraction, neighbours, inferred_stretches, waviness before/after), top-level `boundary_refinement`, file `boundary_curves.npz`. Side buttons unchanged. |
| brain_mouse_recognize_shell | Find bottom plate, top shell, parting seam and sensor window on a READY prepared scan; runs the region step first. Sensor window (S1.1) from mesh geometry only (no pose prior, fixed coordinates, PCB or texture; thresholds relative to the footprint length): aperture outline from exact mesh-edge rim crossings fitted with line + tangent-arc families (rounded rectangle, stadium, U / D shape, four lines + four arcs, generic piecewise polyline fallback; chosen by residual plus complexity) with residual rms / p95 / max and a dense polyline, raster superellipse kept as cross-check, centre, size, depth, 1-sigma uncertainty, ranked candidates, confidence high / medium / low. Parting seam (S1.2, geometry only): exact vertical sections every 0.5 degree, crease + groove cue of the outer wall gated against the plate fillet, circular path search with a smooth low-harmonic prior; closed loop, per-segment support (crease / groove / inferred) and confidence, closure gap, max step per degree, supported fraction. Binary split: bottom plate = skirt below the seam plus the whole underside (feet, label, screws, sensor pocket) as one connected region; top shell = everything above (with the click / wheel / side faces one connected region); The split does not use the region step; the top shell is the parent and body / clicks / wheel / side buttons (region step, unchanged) are its children in `parts_tree`; faces in no part are listed in `regions.unassigned_faces`. split_checks counts rule violations. Writes hashed face labels, seam / sensor outlines and overlay PNGs (both flanks, underside) under mouse/scans/<scan_id>/shell/. Surface-only; no CAD is generated. |
| brain_mouse_register_board_pack | Store a typed PCB mechanical pack. Ready status is refused when required fields are unverified, hashes mismatch, or the STEP is not a valid B-rep. |
| brain_mouse_register_shell_pack | Store a typed prepared-shell pack. Ready status needs a protected outer envelope, a positive wall thickness, matching STEP hash, and a valid B-rep. Scan-to-shell conversion is not performed. |
| brain_mouse_scan_model | PLY scan -> cleaned, decimated, watertight STL for brain_mouse_prepare_scan. unit required (output mm). Exact-position weld first, topology-only cleanup, quadric decimation searched to the smallest face count within target_max_error_mm (default 0.05, hard_limit_error_mm 0.10; two-sided Hausdorff vs the welded original); thin-wall zones are reported separately. Watertight/manifold/winding verified on the written files; report with face counts and max/mean/p99 error under mouse/scans/<model_id>/. Runs PyMeshLab (GPL-3.0) in a subprocess from a separate venv (env CADMCP_SCAN_PYTHON; SCAN_PYTHON_MISSING when absent). Never modifies the source or overwrites outputs. |
| brain_mouse_scan_clean | Re-synthesize under-resolved grooves (mode grooves: click gap, rims, side-button pad rings, found automatically from the region labels or given as seed curves) or repair marked zones (mode zones: boxes, capped by max_zone_deviation_mm, default 0.6) on a READY prepared or scan_model scan. Parametric 3D centre line + trapezoid profile per station, steps explicit; everything outside the edit stays original (outside_tolerance_mm, default 0.05). Writes cleaned STL/PLY, groove_params.json (mm, input frame) and a report with per-groove deviation, roughness before/after, watertight/manifold, self-intersection (UNVERIFIED when the checker is unreliable) and honest limits. Same inputs return the stored report; never overwrites. Runs PyMeshLab in the separate scan Python. |
| brain_mouse_scan_click_grooves | Rebuild the click-panel grooves on a welded watertight STL (standard frame) with face labels (left/right click, wheel; json or npz): vertical-wall slots of slot_width_mm (default 0.5) and slot_depth_mm (default 2.0) around both clicks and a single centre gap (union width = 2 x slot width), the wheel window rebuilt as a rounded rectangle with a flat floor, perimeter slot pushed outward so it never encroaches on the panel edges (perimeter_clearance_mm). Exact manifold3d boolean in a subprocess of the scan python (no PyMeshLab); watertight, one body, cut-through reported (min_wall_mm raises floors optionally). unit required. G1.4: the label outline is a hint; the perimeter is regularised (TLS lines merged over noise kinks, per-vertex G1 fillet radii >= min_corner_radius_mm 0.5), mirrored about the centre-gap line where every region is near-symmetric (symmetry_tol_mm 1.5; optional symmetry_report_path snaps the gap line onto the mouse mirror plane within 2 mm); label spikes narrower than spike_width_mm 2 do not move the slot, overhangs > overhang_mm are reported; the window is a rounded rectangle centred on the gap line. G1.5 window rule: sides = outer envelope of the wheel-well rim and the label notch (window_source envelope|rim|labels), grown until the wheel plan outline + window_clear_mm 0.5 is inside; corner radius = label-notch fit when the notch is as large as the window, else window_corner_frac 0.8 x half the short side, never below window_min_corner_radius_mm 2 (window_corner_radius_mm overrides); WINDOW_SHAPE_IRREGULAR gates radius / aspect (1-4). Gates (NOT_READY): PERIMETER_OUTLINE_ROUGH (6 mm Savitzky-Golay deviation > 0.02 mm or curvature sign changes), WINDOW_OFF_GAP_LINE, PERIMETER_SLOT_ENCROACHES_PANEL_EDGE, PANEL_LABEL_OVERHANG_TOO_LARGE. Writes combined + per-region STL, slot_layout.json (plan layout for brain_mouse_click_slots), overlay PNG and click_grooves_report.json under mouse/scans/<groove_id>/; never overwrites; same inputs return the stored report. Errors: CLICK_GROOVE_KERNEL_UNAVAILABLE (extra scan-grooves missing), CLICK_GROOVE_REGIONS_MISSING, CLICK_GROOVE_MESH_NOT_WATERTIGHT, CLICK_GROOVE_NO_GAP. |
| brain_mouse_scan_symmetrise | Mirror plane of a welded scan STL and scan-error correction only where the part is really symmetric: coarse per-region and per-cell test (p80 mirror residual <= max(2 mm, 1.5 % bbox diagonal)); asymmetric regions, fixed features and the bottom plate kept; never forced. Writes symmetrised.stl, symmetry_mask.npz, mirror_plane.json, symmetry_report.json under mouse/scans/<sy_id>/; cached. Scan python. |
| brain_mouse_shell_fit | Fair B-spline skin of a scan shell region: half + mirror (sewn, exact mirror G1) when the symmetry source says symmetric, else one full face (never forced); waviness under min_wavelength_mm (default 10) rejected; deviation, parameterisation and fairness checks; front_cut auto (default): click rear minus 0.5 mm, stepped back until READY (no clicks: no cut, then the most forward READY cut). Writes shell_skin.step, shell_surface.json under mouse/cad/<sf_id>/; cached. Server python (OCP). |
| brain_mouse_shell_solid | Close a half + mirror shell_fit skin (one front cut) to ONE closed top-shell solid: crease (panel side + lip) from the scan, plain front tube G0/G1 to the skin, cap G1 to the skin with a crisp C0 lip edge, parting = z-const plane when the seam is flat (<= 0.3 mm) else the fitted seam surface; checks valid / one solid / no slivers / STEP re-import / deviation; writes top_shell_solid.step under mouse/cad/<ss_id>/ SS1.2 defaults: seam points on the flank of a wall bulge move onto the crest (seam_to_crest; window 1.0 mm, prominence 0.08 mm, both sides within 0.75 mm, shifts averaged over 4 mm), seam height field smoothing 1e-2. |
| brain_mouse_click_slots | Cut the perimeter slot, centre gap and rounded-rectangle wheel window into a closed shell solid STEP from slot_layout.json or a click_grooves report; mirror from symmetry_report_path (symmetrise report / mirror_plane.json); the perimeter is not cut along the front lip (ends run out), the centre gap starts at the perimeter slot, sliver gate (faces < 0.05 mm2 => NOT_READY); spec widths/depth/window size (overridable); floors follow the B-rep surface; layout symmetrised only where near-symmetric. CS1.3: near-symmetric perimeter averaged with its mirror by arc length from the plane crossing; the window centre is moved onto the gap line (window_on_gap_tol_mm 1) and the gap floor blends into the window floor over gap_window_blend_mm 1.5 (no step); checks perimeter_outline_regular and window_on_gap_line FAIL => NOT_READY. Writes slotted_shell.step, slot_cutters.step, click_slots_report.json under mouse/cad/<cs_id>/; input never modified. |
| brain_mouse_plate_side | Bottom plate (floor + parting surface copy + one straight ruled side) under a shell STEP from a mesh/STEP/polyline base outline (mesh section z auto by default: lowest stable star-shaped z of 0.3-2.0 mm, extrapolated to the floor z = 0, inward only); per-sector symmetrisation (never forced), fairing, clip; front = shell edge minus a uniform 1.2 mm rim by default (rim, corner radius, blend, front direction overridable); checks on re-imported STEP. mouse/cad/<pl_id>/. PS1.5: the floor extrapolation also uses the mesh sections below the chosen section, per angle, while the wall stays continuous (floor_min_z_mm 0.1, floor_max_slope 4 mm/mm), so a rounded foot is measured down to the floor. |
| brain_mouse_face_roles | Face roles (shell/parting/slot/window/panel/sidebutton/sidebutton_wall; plate floor/parting/side) by geometry; optional label hints warn only; coloured XCAF STEP + checks; cached, never overwritten. |
| brain_mouse_handedness_flip | HF1.0, CAD stage after brain_mouse_face_roles: turns a finished right-hand mouse into the left-hand one (or vice versa) by mirroring the WHOLE model (top shell STEP + bottom plate STEP + face_roles.json) about the mouse mirror plane given by symmetry_report_path or mirror_normal + mirror_d (never built in), plus one rigid re-level so the floor is exactly z = 0; nothing is re-designed. Writes top_shell / bottom_plate / assembly / assembly_colored (XCAF) STEP, face_roles.json (side-button roles on the opposite flank), check json and report; gates (NOT_READY): valid solids, floor z = 0, volume equal to the source, side-button flank swapped, face / role counts, face correspondence, colours read back, shell-plate contact preserved. |
| brain_mouse_scan_side_buttons | SB1.0, CAD stage after brain_mouse_click_slots: raised side-button pads with a groove round each on a closed top-shell STEP, written as a NEW STEP. Buttons from side-button labels (hints) of the flushed mesh or, without labels, raised flank patches; 0..max_per_flank (2) per flank, any handedness, never mirrored. Per button: push direction = mean skin normal, outline = convex hull of the points > top_threshold_mm 0.35 above the skin, straight edges re-fitted, corners corner_radius_mm 1.0, one periodic B-spline edge; top = quadratic fit of the scan pad when confidence is high, else skin + default_proud_mm 1.0 (status REVIEW, not blocked); proud_mm forces it; groove groove_width_mm 0.4 x groove_depth_mm 1.5. Gates (NOT_READY): SIDE_BUTTONS_TOO_MANY, SIDE_BUTTON_NOT_ON_FLANK, SIDE_BUTTON_SKIN_DISCONTINUOUS, SIDE_BUTTON_PROUD_OUT_OF_RANGE, SIDE_BUTTONS_OVERLAP, brep_valid / one_solid / reimport / no_slivers / outline_regular / groove_as_specified / pad_proud. Writes side_buttons_shell.step, side_buttons.json, side_buttons_report.json under mouse/cad/<sb_id>/; input never modified. Next: brain_mouse_plate_side and brain_mouse_face_roles on outputs.shell (faces read as sidebutton + sidebutton_wall, green). |
| brain_mouse_scan_flush | Flush a welded scan STL (standard frame x front, y left, z up) onto its bottom plate: area-weighted RANSAC plane on the down-facing plate faces (bottom_plate label from json/npz, else the whole mesh with a warning; inlier band plate_tolerance_mm, default 0.12), refit, tilt removed by the minimal rotation, plate on z = 0; skates/feet end up below z 0 and are reported, never clipped. Rigid only, face order unchanged (same labels stay valid). Returns the transform (Rm, z_shift, 4x4) and residuals: plane-fit area and rms, tilt before/after, percent of plate area within tolerance of z 0, protrusion below the plate. Writes flushed.stl, flush_transform.json, a labels copy and flush_report.json once under mouse/scans/<flush_id>/ (cached, never overwritten); feed flushed.stl to brain_mouse_scan_click_grooves. Subprocess of the scan python (numpy, trimesh; no PyMeshLab). |
| brain_mouse_scan_cable_fill | CF1.0, optional mesh stage after brain_mouse_scan_flush: fill the cable hole / USB pocket of the scan front wall with the PLAIN wall inferred from the trusted wall around it (front height field, robust local quadratic wall, recess >= min_depth_mm 0.8 opened by a min_width_mm 2 disk; per pocket a degree-3 polynomial wall fitted to the ring_mm 4 trusted ring, pocket faces removed, the boundary loop triangulated and lifted onto it, seam blended over blend_mm 1.5). Generic (any pocket position, wired or wireless, asymmetric allowed); wheel / side-button / sensor labels are never trusted wall nor filled. READY = no pocket (mesh + labels copied) or every pocket filled; NOT_READY writes no filled mesh: CABLE_FRONT_WALL_NOT_FOUND, CABLE_INFERRED_WALL_NOT_SMOOTH, CABLE_RING_INCOMPLETE, CABLE_POCKET_TOO_LARGE, CABLE_LOOP_NOT_SIMPLE. Face order changes (kept faces, then the patch): pass report.downstream mesh + labels to brain_mouse_scan_symmetrise, brain_mouse_shell_fit, brain_mouse_plate_side (outline_path) and brain_mouse_face_roles (hints). Writes filled.stl, labels, cable_fill.npz, cable_fill_report.json under mouse/scans/<cf_id>/. Scan python. |
| brain_mesh_backend | User-selectable mesh backend per operation (hausdorff / simplify / fill_holes) for brain_mesh_ops: status lists numpy (studio code, in process), pymeshlab (scan python, GPL-3.0) and cgal (separate cgal-mcp service over stdio JSON-RPC, never linked; Master 1.0.0 hausdorff / simplify <= 400 faces) with offers, licence, limits, cost and availability; select / clear store the user's choice in this workspace only (.cadmcp/mesh-backend.json). Nothing is chosen automatically. |
| brain_mesh_ops | Generic mesh operation (hausdorff, simplify, fill_holes) through the user-selected backend; no choice => NEEDS_USER_CHOICE with options; absent backend => BACKEND_UNAVAILABLE, cgal refusal => REFUSED, no silent fallback. Every mesh result re-measured by the same studio exact-distance check; report backend, cgal_used, cgal version / plan / job / validators, seconds. New files under mouse/mesh_ops/<mo_id>/; sources never modified. Mouse chain tools unaffected. |
| brain_mouse_structure_gate | Report whether a ready board pack and a ready shell pack exist. Does not generate structure CAD, bosses, or click parts. |
| brain_open | Start source-grounded design. request is the user's exact original text, not an invented paraphrase. Next call brain_task. |
| brain_patterns | Retrieve original mechanism patterns using lexical English/Japanese search. Results are not validated designs or dimensional allowables. |
| brain_schema | Read a versioned Brief, Concept, Concepts or Plan JSON schema. |
| brain_select | Select a gate-eligible concept. This does not attest human approval, printability, strength or fatigue life. |
| brain_studio_build | Build a STEP-bound typed CAD recipe in a separate process; export real STEP/STL/SVG and static/sampled-motion clearance. No arbitrary Python exec, printer send or canonical project modification. |
| brain_studio_reply | Record an evidence-based response to a specific review finding. No majority vote or prose rebuttal automatically clears a blocker. |
| brain_studio_review_packet | Prepare a requirements/mechanism/assembly/manufacturing/verification reviewer packet with real evidence and exact output schema. This does NOT spawn an independent LLM itself. |
| brain_studio_review_status | Read review coverage, open disagreements, geometry failures and unverified physical requirements. Reviewer independence and human approval are never inferred. |
| brain_studio_schema | Get FunctionBrief, Matrix, Recipe, Review, Reply, BoardPack, ShellPack, FusionHandoff or FusionReport schemas. These are typed host/worker contracts, not a claim of semantic intelligence. |
| brain_studio_submit_review | Record actual host-submitted engineering findings for this revision and subject. Roles and agreement never authenticate independent reviewers or clear physical tests. |
| brain_studio_synthesize | Combine real-reference mechanism options into compatible functional covers. Reject absent required surfaces and invented face IDs. Returns review subjects, NOT finished assemblies. |
| brain_submit_concepts | Commit 2–4 distinct FBS mechanism alternatives and return mechanical/declaration gate results for each. |
| brain_submit_intent | Validate and commit the source-linked Brief. Reject source omissions, fabricated quotations, contradictory constraints and mandatory inferences. |
| brain_submit_plan | Commit a typed geometric construction plan with dependency, provenance and test-obligation validation. |
| brain_task | Get the next host-model task, relevant state and exact JSON schema. The server does not pretend to understand natural language itself. |
| brain_verify | Measure imported B-reps and evaluate listed geometry checks. Missing/stale/unsupported evidence remains unknown; physical performance is not certified. |
