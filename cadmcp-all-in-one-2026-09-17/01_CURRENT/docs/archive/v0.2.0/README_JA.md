# cadMCP Design Brain v0.2.0 — Req2CAD Function–Structure KB

**機能から実在する参照CADを探し、その形状・トポロジーを確認して構造設計へ渡すための更新版です。**
旧版の「13種類の自作カード検索」は補助へ下げ、Req2CADの元注釈を全件取り込むデータベース、機能語単位の埋め込み検索、DeepCADとのUID対応、実CADの再構成・測定を追加しました。

- ソース、CLI、24個のMCPツール、導入スクリプト、Skill、テスト、著者作成の実行試験片を含みます。
- **全件CSV、DeepCAD全データ、Qwenの学習済み重みは同梱されていません。** 作成環境で公開ファイルの一括取得が失敗しました。導入スクリプトが所有者の環境で原配布元から取得します。
- Qwen本体を使った実推論、全件データでの検索精度・幾何再構成成功率、Windows/Cursor/Codex実クライアントは未検証です。
- 原論文の「機能→CAD」「キーワード埋め込み」「B-repのWLトポロジー」を参考にした独立実装です。原版アプリ全体や学習済み点群ネットワークの完全再現ではありません。
- `examples/req2cad_fixture`は**このソフトの作者が作った試験データ**です。元Req2CADのUIDと偽って結び付けていません。

詳しくは `REQ2CAD_IMPLEMENTATION_JA.md`、`TEST_REPORT_JA.md` を参照してください。

## 実装した中核

```text
ユーザー要求
  → ホストLLMが機能を分解（verb + object）
  → Req2CADの機能語を意味検索
  → 実在UIDの候補、対応した機能と類似度
  → 対応するDeepCAD JSON / STEPを実際に読む
  → B-rep再構成、STEP/STL、4方向SVG
  → 面種別・面隣接グラフ・WL特徴、表面形状特徴
  → 異なる構造候補の比較
  → CAD出典、採る原理、適合のための変更点をConceptへ登録
  → 既存cadMCP / AgentCAD等で対象製品を設計・検査
```

1件のCADが複数の機能に結び付き、1機能も複数のCADに結び付きます。候補は架空の説明文から生成するのではなく、取り込んだ元行のUIDを返します。形状が存在しないUIDには形状を作りません。

## 最初の導入

前回版とは別フォルダへ展開してください。PowerShell:

```powershell
.\setup.cmd --geometry
.\setup_req2cad.cmd --download-deepcad --reference-only
```

後者はネットワークから全CSV・DeepCADアーカイブ・埋め込みモデルを明示的に取得し、検索索引とUID対応を作ります。ディスクを使用し、CPU/GPUで埋め込みを計算します。追加の有料LLM APIは呼びません。失敗時に成功扱い・サンプルデータへの置換はしません。

`--reference-only` は元部品の実寸単位が未確認でも、形状・構造の参考として扱う設定です。幾何数値は `*_model_units` と明示し、実物のmm寸法だと表示しません。マウスへ転用する寸法は、実際の基板・スイッチ・シェルを測って決めます。

CAD全件を最初からB-repに変換するのではなく、検索後に使う候補を `brain_fs_materialize` で必要時に変換してキャッシュします。全件事前変換コマンドもありますが、検索利用開始の必須条件ではありません。

生成された `integration/generated/cursor.mcp.json` または `codex.config.toml` の該当サーバー項目を、既存の設定へマージします。既存設定全体を置き換えないでください。

## モデルへ渡す指示

```text
README_JA.md、INSTALL_INTEGRATE_JA.md、REQ2CAD_IMPLEMENTATION_JA.mdと
.agents/skills/cadmcp-design-brain/SKILL.mdを読み、brain_fs_statusを実行してください。

参照UID、evidence_digest、採る原理、変更すべき寸法・接続を構造案に記録してください。

データ未取得や検索失敗を、架空のUID・架空のモデル・黙った字句検索で埋めないでください。
サンプルデータを元Req2CADと呼ばず、参考形状をそのまま印刷可能・耐久性確認済みと判断しないでください。
```

## 旧版からの変更・互換性

旧版機能を残し、7個の `brain_fs_*` ツールと参照根拠フィールドを追加しました。新しい導入スクリプトの設定では `CADMCP_REQUIRE_CAD_REFERENCES=1` を有効にし、測定済みCAD参照を機構へ結び付けていない構造案は進めません。既存v0.1互換運用ではこの環境変数を設定しないことで旧来の探索的案を扱えます。

**古いworkspaceを上書きしないでください。** 新しいモデル項目により契約ハッシュが変わります。旧成果物は保存し、新workspaceへ原要求と参照データを再登録します。旧版の検証資料は `docs/archive/v0.1.0/` に履歴として保管しています。

## 物理・意味理解の境界

機能注釈はVLM/LLMによる推定であり、全件が検証済みの機構ではありません。形状やトポロジーが似ていても、荷重、摩擦、復帰力、組立、隙間、疲労、積層方向を検証する必要があります。検索ヒットは設計の出発点であって完成品の合格証ではありません。
