固定姿勢の剛体直線並進では集合間距離が移動量に対して1-Lipschitzという性質を利用し、等間隔標本の最小距離から標本間移動量の半分と仮定した数値誤差を差し引いています。**1e-6 mmのカーネル距離誤差は保証済みの誤差上界ではなく仮定**です。回転・弾性変形・実寸公差・造形・摩擦・疲労まで証明したものではありません。動作検査の判定名にもこの条件を残しています。

元JSONの表示倍率1000は物理単位の認定ではありません。加工後の3.0/3.3 mm等はソフトウェア試作用の設計選択で、実マウス・QIDI Q2・ABSの推奨値ではありません。

`examples/real-reference-output/`のSTEP/STL/PNG/SVG/recipe/measurements/HTMLが実成果物です。保存時の絶対パスは実行時の出典記録であり、ユーザーのMCP設定へコピーしないでください。再実行で自分のパスを生成します。
