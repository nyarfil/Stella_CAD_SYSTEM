# 実装レビューと修正記録

これは**本作業で単一アシスタントが複数の技術観点から行った実装レビューの要約**です。独立した人間・LLMチームを実行した会議録ではありません。実際の5役モデル実行は所有者側CLIに実装し、通信・順序・異常系をスクリプト応答で検証しました。

| 論点 | 検討した代案 | 採用と検査 |
|---|---|---|
| 注釈だけの参考構造 | 機能語に似たラベルだけで採用 / 実形状を読む | 実CAD面・方向・穴の内外を測定。中実軸を穴付きガイドとして採用する負例を拒否 |
| 元輪郭のis_outer | フラグ盲信 / 幾何の包含関係 | 実データの入れ子円でフラグ矛盾を検出。包含深さの偶奇で材質領域と内孔を復元、接触・重複は拒否 |
| 複数機能検索 | 言い換えを独立票として加算 / 機能単位で集約 | 同機能内max、機能間coverageを分離。制御ベクトルで二重投票を防ぐ試験 |
| パターン集合 | 固定13カード / 未検査の何でもあり / 実例付き拡張 | 実UID・出典hash・使うface IDを必須にした参照方式。引用した面で前提を検査 |
| 自由生成コード | LLMのPythonをexec / 型付き操作集合 | typed Recipeを実カーネルで実行。未対応操作は失敗、指定Rを黙って変更しない |
| 保護部品 | 自己申告roleのみ / 所有者指定ID | 保護/編集権限を所有者起動設定に分離。位置変更・ブーリアン対象化・出力省略を拒否 |
| 干渉漏れ | 指定ペアだけ / 全出力ペア自動検査 | 全ペアの体積重複を自動確認。必要隙間は明示の追加条件 |
| 動作の抜け | 数点の合格で全区間合格 / 下界と追加サンプル | 固定姿勢の直線並進に限定し距離のLipschitz下界で補間間隔を管理。数値誤差は仮定と表示。回転/変形は未検証 |
| 討論の質 | 一役の自己採点 / 同時に相手回答を見る / 独立初回＋相互反証 | 初回5役後に2巡目へ具体的指摘を渡す。評価の独立性/性能は未証明 |
| 修正で合格逃れ | 原条件を書き換える / 条件を固定 | 原文・寸法・隙間・動作・物理未検証項目を凍結。悪意ある修正出力の負例を拒否 |
| 包装だけ成功 | ソースから関数だけ呼ぶ / 配布wheelと実stdio | 全試験と追加の配布検査を別記録。実データ/数値fixture/スクリプト応答を分ける |

主な実装位置：`studio/synthesis.py`、`recipe.py`、`interfaces.py`、`runtime.py`、`autopilot.py`、`provider.py`、`wire.py`、`render.py`、`req2cad/geometry.py`、`assets.py`、`semantic.py`。負例は`tests/test_studio.py`にあります。

未解決の高優先項目は、全件原本と実埋め込みによる検索評価、実モデルによる雑指示→妥当構造の評価、ユーザーの実PCB/シェルでの適合、実造形・疲労です。これらを単体試験数や多数決で代用しません。
