# Open Issues

### CONFLICT-001 [RESOLVED 2026-07-13]
- **Parts**: lid, base_box
- **Issue**: Closed-lid interpenetration. The lid's hinge lugs embed to local Y=-57 (inner dome radius) for a solid union with the shell, but the dome only exists for local Z>=0. Below the rim plane (local Z=-4..0 -> global Z=76..80 when the lid is placed at (0,0,80)), the bare Y=-60..-57 slab of each lug lands INSIDE the base_box rear wall (wall spans Y=-60..-57, Z=0..80). Interference volume: 15 x 3 x 4 mm = 180 mm^3 per lug, 360 mm^3 total (X = 29.5..44.5 and -44.5..-29.5, Y = -60..-57, Z = 76..80). The lid's own constraints.md specifies the below-rim tab as Y=-74..-60; the code drifted to -57 for the union merge and the part-level validation could not see the assembly-level consequence (designer's note explicitly reasoned "base outer wall is at Y=-60" but only checked Z>=0).
- **Proposal**: assembly/lid/part.proposal.py (adds `lug_underhang_trim` feature — one cut box Y=-60..-50, Z=-8..0, full X width — trimming the below-rim slab back to Y=-60 flush contact; the Z>=0 embedment inside the 3 mm dome wall is untouched. Verified by executor: builds OK, bbox unchanged 180 x 134 x 64, volume delta exactly -360.00 mm^3 = the interfering slab and nothing else.)
- **Recommendation**: lid should yield. base_box is correct per plan (rear wall at Y=-60..-57 to Z=80 is the plan geometry, and 3 other parts locate off it); the lid code deviated from its own constraints.md ("lug body: rectangular tab spanning Y=-74..-60"). The fix is additive-surgical (one new feature function), preserves the designer's legitimate manifold-union embedment above the rim, and restores the specified flush contact below it.
- **Affected by**: lid constraints.md Features ("tab spanning Y=-74..-60"); lid notes.md "Constraint discovered during design" (the deliberate -57 embedment — valid rationale, incomplete Z-range analysis); design_plan.md interface "lid <-> base_box" (rest contact, no interpenetration).

- **Resolution**: Proposal ACCEPTED via DFM regression gate: verdict=promoted, score 5->5, delta 0, no new failures. lid/part.py now carries lug_underhang_trim; interference removed (volume -360.00 mm^3 exact, bbox unchanged). Resolved by orchestrator.
