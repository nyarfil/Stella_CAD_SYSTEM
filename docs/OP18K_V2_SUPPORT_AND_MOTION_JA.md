# OP18K v2 + ZA13左手専用マウス：支持と可動機構の設計契約

## 1. この文書が固定するもの

対象は、`V:/mouse/ZA13/{top,bot,side,button}.stl` の外形・分割を参照し、固定電子部品として `V:/mouse/op18kv2pcb_251212.step` を使う左手専用マウスである。メインPCBと主クリック小基板は、底ケースではなく**新設するミドルシェル天井から吊るす支持構造**へ取り付ける。OP18K基板を左右反転した形状にはしない。

この文書は、形を描く前に荷重経路、拘束、復帰、停止、組立順を固定する機構契約である。形状寸法のない項目は設計変数のまま残す。静止STEP/STLだけではスイッチの作動量、許容最大押込み、力曲線、材料、疲労寿命を確定できない。

## 2. 根拠の区分

| 区分 | この設計での扱い |
|---|---|
| 実測 | STEP/STLから測った外接箱、円筒軸、穴、面中心と法線。形状事実だけを表す |
| 提案 | 支持方式、剛体配置、可動部、復帰源、停止部、組立順。CADで作る対象 |
| 未確認 | 部品の電気機能、実スイッチ型番、作動量・力、穴の用途、材料、印刷公差、実物個数、耐久性 |

形状測定の一次記録は [OP18K形状調査](examples/op18_alternate_hardware_intake.json)、[OP18K機能面候補](examples/op18_hardware_interfaces.json)、[ZA13メッシュ調査](examples/za13_left_source_mesh_intake.json) とする。OP18 STEPはmm宣言、SHA-256は `94e3e7bcd46503b0c135d2e229bf7d35d33ca935456e67450282dceb3cc9be4f`。ZA13 STLの座標単位はファイル内に宣言されていないため、OP18との数値を直接混ぜない。

Endgame Gearの[公式FAQ](https://help.endgamegear.com/hc/en-us/articles/19659564693789-Can-I-change-the-switches)は、機械式OP1のV1/V2で主スイッチをはんだ無し交換できるとしている。[公式Universal Switch Set](https://endgamegear.com/products/op1-universal-switch-set)は、2個のスイッチがそれぞれOP1 switch PCBへ実装され、switch PCBをtop shellへ取り付ける構成を説明している。これは天井側の左右独立小基板を支持する機能根拠になるが、穴・作動量・力・外形寸法の根拠にはしない。

### 2.1 現時点で使える形状事実

- ZA13 `top.stl` は1接続成分で、前方に左右のクリック領域、中央にホイール開口、両クリック間の継ぎ目がある。後方の円筒柱候補は接続・締結機能をまだ確定していない。
- ZA13 `side.stl` は正X側だけに存在するが、ファイル名だけでサイドボタンや左手用接触部とは認定しない。`button.stl` も主クリックとは認定しない。
- OP18 `main_pcb:1` の薄板は `x=-13.8..14.0, y=-33.6..39.3, z=6.6..7.4 mm`。半径1.4 mmの閉じた円筒境界が3個、端で切れた円筒境界が1個ある。材料は半径方向外側にあるが、貫通穴か止まり穴か、取付用途かは未確認。
- OP18 `main_switch:1` の薄板候補は `x=-23.9..-16.1, y=15.2..42.6, z=6.6..7.4 mm`。半径2.325 mmの閉じた円形境界中心は `(-20,20.9)` と `(-20,39.1) mm`。材料は半径方向外側にあるが、貫通穴か止まり穴か、取付用途かは未確認。同じXCAF occurrence内には、大形の `#o1.6.s2` と小形の `#o1.6.s3` がある。上向き面候補はそれぞれ中心 `(-20,31.95,14.75) mm`、面積 `3.48 mm^2` と、中心 `(-20,16.6,9.1) mm`、面積 `1.6963 mm^2`。小形 `s3` を反対側主クリックとは扱わない。
- `main_pcb:1` 内の大形部品 `#o1.4.s8` と、小基板上の `#o1.6.s2` は、上面積、下面積、上下Z、全高 `10.55 mm` が数値誤差内で一致するBRepペアである。両方の上向き接触候補面積は `3.48 mm^2`、Zは `14.75 mm`。これは大形筐体ペアの形状根拠であり、電気機能や物理的な左右名称の証明ではない。

## 3. 固定系と反力の閉じ方

固定系は、新しいミドルシェル、底ケースとの締結、天井側のメインPCB支持、主クリック小基板キャリア、ホイール支持、サイド基板支持からなる。トップの指接触面と各ボタンは可動系として固定系から分ける。

主クリック時の主荷重経路は次のように閉じる。

`指 -> 独立クリックキー -> 調整接触子 -> スイッチ可動部 -> スイッチ筐体/実装 -> メインPCBまたは主クリック小基板 -> 各基板下面支持橋 -> ミドルシェル天井から下りるリブ/ボス -> ミドルシェルと底の締結 -> 手・机`

基板を天井へねじで吊るすだけでは、押下時の下向き荷重をねじ軸力と基板曲げだけで受ける。採用案では両基板の下側に支持橋を置き、各主クリック候補の近傍で荷重を圧縮で受ける。ねじは保持と支持橋の固定を担当し、基板の位置決め、Z支持、保持、挿入経路を同じ形状に兼務させない。

`lens`、`around lens`、`sensor`、`main_pcb` の相対姿勢は、機能資料で分離可能と確認するまでOP18アセンブリのまま保つ。メインPCBを天井支持した状態で、レンズと底面の光学姿勢を決める。クリック反力を受ける支持橋は主クリック候補の近傍へ置き、センサーやレンズ周囲の基準面へ反力を流さない。天井と底の結合公差が光学高さへ入るため、光学姿勢は天井支持の合格条件になる。

## 4. メインPCBと主クリック小基板の天井支持：3案比較

| 案 | 拘束と荷重経路 | 長所 | 固有の失敗 | 判定 |
|---|---|---|---|---|
| A. 天井ボスへのねじ吊り | 穴とねじでXYZを拘束し、押下反力をねじと基板曲げで天井へ戻す | 部品が少ない | 穴用途未確認、基板の局所曲げ、締付けで反り、ねじ緩み、光学姿勢とクリック支持が締付けに依存 | 不採用 |
| B. 天井から下ろした周囲レール | 各基板の外周を連続棚で受け、爪かねじで保持する | 造形が単純、広い面で支持 | 部品・はんだ面と干渉しやすい、外周公差で過拘束、挿入方向が限定される | 条件付き |
| C. 2つの下面支持カセット | メインPCB用と主クリック小基板用に別の支持橋を設ける。各3支持点でZを定義し、別の1基準+1方向基準でXYを決め、別部品で保持する | 押下荷重を圧縮で受ける。光学姿勢、主クリック反力、交換を分けて検査できる | 支持橋とボスの剛性、工具経路、部品面の逃げ、実穴用途を要確認 | **採用候補** |

採用候補Cには、証拠の食い違いを解消するまで2つの組立分岐を残す。

- **提供STEP分岐**: メインPCB上の `#o1.4.s8` と、`main_switch:1`小基板上の `#o1.6.s2` を左右候補として、メインPCBと小基板を元の相対姿勢で支持する。
- **公式実機分岐**: 物理部品が公式説明どおり2枚のswitch PCBなら、実測した各小基板を左右別カセットで天井支持し、メインPCBは光学・配線用の別カセットで天井支持する。

`#o1.6.s3` を2つ目の主クリックへ流用しない。どちらが左・右入力かは電気確認で決める。基板形状の鏡像や、未測定の第2小基板形状をCAD内複製して実物扱いする操作はしない。物理キット、BOM、分解写真のいずれかで分岐を確定する。

3点支持の位置は、それぞれの主クリック荷重点を含む支持多角形になるよう決める。メインPCBの半径1.4 mm円筒境界群と小基板の半径2.325 mm円筒境界群は保持・位置決め候補にすぎず、貫通と取付用途が確認できるまでポストやねじを通さない。支持橋には部品・はんだ・配線の実測keep-outを設ける。

## 5. 主クリック可動部：3案比較

| 案 | 自由度・案内・復帰 | 調整と停止 | 主な故障 |
|---|---|---|---|
| 1. ZA13表皮と一体の曲げ舌 | 弾性体なので回転1自由度ではない。根元曲げとスイッチ反力で復帰 | 接触子だけ調整可能。別の上下停止を追加 | 握り変形との干渉、左右連成、クリープ、根元疲労、層間割れ |
| 2. 独立剛体キー+交換式板ばね根元 | 小角度回転に近いが板ばねは弾性体。左右それぞれの根元ばねが復帰。側面ガイドは隙間を持たせる | 交換式接触子/ねじ、上停止、下停止を各キーに設ける | 板ばねの材料・印刷方向依存、ガイド摩擦、締付け範囲でばね長が変化 |
| 3. 独立剛体キー+ピン軸+独立ばね | 意図した回転1自由度。軸受が並進3方向と他の回転2方向を拘束。根元の独立ばねで復帰 | 接触高さ、上停止、下停止を独立調整できる | 軸同軸度、ガタ、摩耗、軸抜け、ばね組付け、接触点の横滑り |

**実装候補は案3**とする。理由は、左・右クリックの運動、復帰、接触高さ、停止位置を分けて検査できるためである。外側の指接触面はZA13の前方クリック領域を参照するが、左右キーは別部品にする。共通の横棒、共通ばね、中央をつなぐ薄いウェブは使わない。

各キーは後方根元のピン軸で支持し、根元に左右独立の復帰ばねを置く。スイッチとの休止隙間が正なら、接触が離れたあとスイッチばねはキーを上停止まで戻せないため、独立ばねは必須である。側面ガイドは横ずれとヨーだけを制限し、回転を締め付けない。

接触子はスイッチ候補面の法線へ荷重を入れる。ねじを使う場合は緩み止めと工具経路を設ける。接触高さを変えると休止遊び、ONまでの移動、残る過押込み余裕が同時に変わるので、調整可能であること自体を成立根拠にしない。

可動包絡は、休止から下停止までキー全体をピン軸回りに掃引して作る。指面だけでなく、接触子、ばね、抜け止め、側面ガイドとの最小隙間を含める。接触子は円弧を描くため、スイッチ面上の横滑りと横力も同時に追跡する。

### 5.1 四状態の契約

| 状態 | 必須条件 |
|---|---|
| 休止 | 独立ばねがキーを上停止へ戻す。スイッチはOFF。握り込み、反対側押下、シェルねじ締付けでONにしない |
| ON | 下停止へ当たる前に、接触子のスイッチ軸方向相対閉鎖がON閾値を越える |
| 最大押下 | キー側の下停止がミドルシェルへ当たり、その後の指荷重をスイッチでなく固定系へ逃がす。ケースと支持橋のたわみを含めても許容押込みを超えない |
| 復帰 | 独立ばねの最小復帰モーメントが摩擦、配線、ガイド、重力、逆向き変形を上回り、OFF閾値を通過して上停止へ戻る |

一般化変位を `q`、接触点とスイッチ支持の軸方向相対閉鎖を `u(q,F)`、符号付き休止隙間を `g` とし、単純な片側接触では `delta=max(0,u-g)` とする。区間公差を入れた最低条件は次である。

- ON前余裕: `max(0,u_pre_stop.min-g.max) >= on.max+m_on`
- 復帰後OFF: `max(0,u_rest.max-g.min) <= off.min-m_release`
- 最大押込み: `max(0,u_post_stop.max-g.min) <= allow.min-m_safe`

ON/OFF閾値、許容最大押込み、支持変形、公差が実測されるまで数値窓を確定しない。ピン軸機構の力比は距離の単純比でなく、軸から各力線までの垂直距離または `F_finger*du_f/dq = F_switch*d(delta)/dq + Q_return + Q_loss` で評価する。最大押下では `指 -> キー -> 下停止 -> ミドルシェル` が主経路となり、スイッチ側へ追加荷重を流さない。休止では根元ばねの荷重を `キー -> 上停止 -> ミドルシェル` で受ける。

## 6. ホイール機構

ホイールは回転 `theta` と中央クリック変位 `q_m` を別自由度として設計する。静止STEPで確認できるのはX方向の同軸円筒群だけであり、回転検出器、反対側支持、中央クリックの支点、復帰源は確定していない。

### 比較する支持原理

1. 片端を回転検出器へ結合し、反対端を上下移動可能なサドルで受け、全体を小角度回転させて中央スイッチを押す。
2. ホイールと両端支持を小さなクレードルに載せ、クレードル全体を平行に近い上下運動させる。
3. 両端を固定軸受にし、中央クリックを別の可動キーで押す。

回転検出器の実在位置と中央スイッチの接触方向が確認できれば案1を優先する。部品点数が少なく、回転と押下を分けて追跡できるためである。ただし、押下中に軸結合が抜けず、サドルが軸を固定し過ぎず、専用ばねが休止位置へ戻すことが条件となる。`bush:1` は軸方向が違うため、このサドルへ自動採用しない。

ホイールの荷重経路は `指 -> ホイール/軸 -> サドルと回転検出器支持` と、中央クリック時の `ホイール/クレードル -> 接触子 -> 中央スイッチ -> その支持 -> ミドルシェル` に分ける。最大押下にはスイッチ以外の下停止を置く。回転包絡は測定済み軸と実形状から作れるが、中央押下を重ねた掃引包絡は支点・移動量決定後に作る。静止干渉だけで回転・押下の成立を認定しない。

| ホイール状態 | 必須条件 |
|---|---|
| 休止/回転 | `q_m`は上停止、中央スイッチOFF。使用角度全域で`theta`が自由で、軸抜けや外装擦れがない |
| 中央ON | 下停止前に中央スイッチがONし、同時に軸結合と回転支持が外れない |
| 最大押下 | 専用下停止が荷重をミドルシェルへ逃がし、中央スイッチの許容押込みを超えない |
| 復帰 | 専用復帰源が摩擦と軸拘束を上回り、中央スイッチをOFFにして上停止へ戻す |

ホイールの可動包絡は、回転だけの包絡、中央押下だけの掃引、押下中の回転を含む複合包絡の3つに分ける。支点と押下量が未確定な現在は、回転軸と静止外形だけが実測済みであり、複合包絡は未成立である。

## 7. 左手用サイド入力

左手親指側を新しい右側、すなわち設計座標の正X側とする。この方向はCAD表示で使用者視点と照合してから固定する。OP18 `side_switch:1` は鏡像化せず、**Z軸回り180度の剛体回転と平行移動**を第一配置候補とする。元姿勢の負X小面候補は回転後に正Xを向くため、右側外装から負X方向へ押す配置を作れる。前後の並びも反転するため、前後ボタンの電気割当と指位置は別に確認する。

サイドキーは前後2個を別部品にし、各キーを短いピン軸ロッカーまたは交換式根元ばねで支持する。共通の長い板で2スイッチを押さない。各キーに上停止、下停止、独立復帰、接触子を置き、片方の最大押下と通常の握力で他方がONにならない条件を設ける。

サイド入力の反力は、薄い外装壁だけでなく、`side_switch`支持キャリアからミドルシェル天井と側壁の交差リブへ戻す。基板の外向き面は外形keep-outであり、小さい面を実プランジャと確定するには実物または部品資料が必要である。

| サイド状態 | 必須条件 |
|---|---|
| 休止 | 各キーが独立した上停止にあり、2入力ともOFF。通常の握力でONにしない |
| 片側ON | 選んだキーだけが接触面法線方向へ動き、下停止前に対応入力をON。他方の接触閉鎖はOFF余裕内 |
| 最大押下 | 選んだキーの下停止が反力をキャリアへ逃がし、基板と隣接キーへ過荷重を渡さない |
| 復帰 | 独立復帰源が側面摩擦を上回り、対応入力をOFFにして上停止へ戻す |

サイドの可動包絡は各キーを単独で掃引した2包絡と、片側最大押下時の隣接キー・親指・シェルとの隙間を含む。Z軸回り180度の配置候補は静止姿勢の提案であり、入力面の作動量が得られるまで掃引成立とはしない。

## 8. 組立順

1. ミドルシェルを下面から作業できる姿勢に置く。
2. OP18光学部品との相対姿勢を保ったメインPCBと、`main_switch:1`小基板を各支持カセットへ載せる。3点支持、XY位置決め、クリック候補付近の下面支持、部品逃げを目視できる状態で保持橋を固定する。
3. ホイールの回転検出側、反対側サドル、復帰部、中央クリック接触子を組む。回転と押下を手で独立確認する。
4. `side_switch`を正X側キャリアへ剛体配置し、前後の独立サイドキーを組む。
5. 左右主クリックキーのピン、抜け止め、根元ばね、接触子を組む。上停止から下停止まで手で動かす。
6. センサーとレンズの光学経路、底開口、追跡面までの姿勢を確認する。光学部を底支持で追加拘束する場合は、天井支持と競合しない自由度を残す。
7. ミドルシェルと底を締結し、トップ外形を閉じる。閉鎖後にも接触調整ねじと主要締結へ工具が届くか、調整後に封止する工程を先に定める。

組立中にばねを無理に曲げる、ピンを完成外装越しに差す、主PCBを外さないとクリック基板を交換できない、といった経路は採用しない。

## 9. CADレシピへ渡す設計変数

### 実測値として固定できる入力

- OP18各BRepの外接箱、上記穴中心・半径、面中心・法線・面積。
- ホイールのX軸と検出済み円筒半径。
- ZA13各STLの元形状と座標。ただしSTL単位とOP18座標系の関係は別途確定する。

### 提案値として設計・実測が必要な入力

- `T_op18_to_mid`、`T_main_pcb`、`T_main_switch_board`、右側 `T_side_switch`、2つの主クリック候補と左右キーの対応表。
- メインPCB支持橋と主クリック小基板支持橋の各3支持点、部品keep-out、保持位置、ねじ仕様、工具包絡。
- ピン軸、軸受隙間、キーの質量中心、指位置範囲、接触子位置、符号付き隙間 `g_L/g_R`。
- 根元ばねの材料、断面、初期姿勢、最小復帰モーメント、寿命目標。
- 上停止・下停止の位置と接触面積、スイッチのON/OFF閾値、許容最大押込み、力曲線。
- ホイールの軸結合、サドル、中央クリック支点・復帰・停止・掃引包絡。
- サイドキーの押下方向、休止隙間、前後割当、握力条件、相互作動上限。

### CAD作業順

1. 元STLを参照ボディとして固定し、左手用の外面と使用者座標を宣言する。
2. OP18全ソリッドを保護参照として配置し、許可した剛体変換だけを記録する。
3. 新規ミドルシェル天井、底との締結、OP18光学相対姿勢を保つメインPCB天井支持を作る。
4. メインPCBと主クリック小基板の独立した下面支持カセットを作り、各クリック候補近傍で荷重を返す。
5. 左右独立のピン軸キー、根元ばね、接触子、上下停止を作る。
6. ホイール支持と中央クリック、正X側のサイド基板キャリアと前後キーを作る。
7. 休止、ON、最大押下、復帰の4状態を別姿勢として保存し、静止干渉と掃引包絡を確認する。

## 10. 失敗モードと合格ゲート

| 失敗 | 必須確認 |
|---|---|
| 主クリック基板がたわみ、クリック量を吸収する | スイッチ荷重点を含む支持多角形、支持橋と天井の変形 |
| ねじ締付けで基板が反る | 3点支持、保持力、締付け順、スペーサ高さ |
| 天井支持の変形・公差でセンサーとレンズの姿勢がずれる | OP18相対姿勢、天井から底までの公差列、追跡面までの光学高さ |
| 片側クリックで反対側も動く | 左右独立軸・ばね・停止、固定系変形を含むクロストーク |
| 接触後にキーが上停止へ戻らない | 独立ばねの全範囲復帰モーメントと摩擦上限 |
| 最大押下をスイッチが受け続ける | 下停止接触後の追加変形を含む押込み上限 |
| 接触子が円弧移動してプランジャを横に擦る | 全ストロークの接触点移動、横力、摩耗 |
| ホイール押下で軸結合が抜ける/回転が重くなる | 回転+押下の複合姿勢、軸方向保持、サドル拘束 |
| 左手用サイド基板の向きが逆 | Rz180剛体変換後の面法線、前後電気割当、親指位置 |
| 側壁がたわんでサイドボタンが誤作動する | 支持キャリアから天井/側壁交差部までの反力経路 |
| 組めない・直せない | ピン、ばね、ねじ、配線の挿入経路と工具包絡 |

現段階で成立したのは機構の選択と検証契約である。固定寸法の機構CAD、実スイッチの作動窓、回転/押下掃引、FDM寿命、実物適合はまだ合格していない。

現在のClassCAD読込系は元のZA13 STLを編集可能なシェルとして受け付けず、今回の読込試行でも既存モデルは変更されていない。したがって元STLは保護された形状参照であり、この文書を作成した時点では新しいミドルシェル、キー、支持カセットの実ソリッドはまだ生成していない。次工程では、変換後の形状または別のCAD読込経路で元外形を保持し、この契約に従って新規部品を作る。
