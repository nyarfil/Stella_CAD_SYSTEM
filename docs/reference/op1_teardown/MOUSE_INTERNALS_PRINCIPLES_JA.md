# マウス内部構造 共通ルール(オーナー指示 2026-10-11。どのマウスでも共通。MCPの前提知識)

## 基板セット(OP1 の f3d: V:\mouse\OP1-PCB\op18kv2pcb_251212_only.f3d。作業コピー: V:\mouse\LH2-mouse\work\internals\pcb\)
| 部品 | 意味 | 使い方 |
|---|---|---|
| センサー / レンズ / メインPCB | 1つのセット = 基板本体 | 丸穴の柱+ネジで底板に固定 |
| アラウンドレンズ (around lens) | 制作時の補助部品(実物ではない) | レンズを収める部分を作るときの型。**下面を底板の下面に合わせる**と、センサーの台座兼光漏れ防止が一度で作れる。センサー距離の問題は起きない(OP1と同じ位置関係) |
| wheel | 基板付属のホイール本体 | そのまま使う |
| sideSwitch | サイドボタンのスイッチ基板 | 右利き用データ。左利き用は**ひっくり返して**使う |
| メインスイッチ (main switch) | メインクリック用スイッチ基板 | データは1枚だけ。実際は**コピーして左右計2個**にして使う |

## 固定ルール
1. 基板の丸穴に、円柱(ポスト)をはめてネジで止める。
2. **メインスイッチ基板の固定先は、指示がない限り底板ではなく上シェル側**にする(分割型=上部シェル、一体型=ミッドシェル)。底板に置くと、クリックのプリトラベル/ポストトラベルのクリアランス調整の難易度が跳ね上がり、安定しない。
3. 固定は「ネジ穴付きの固定用柱 + ストッパーを兼ねたリブ」の組(写真 09_top_shell_click_area_switch_post.webp、丸囲み部)。
4. 写真09の読み方: OP1 上シェルの裏側、クリック部付近。右側=クリック部の別パーツを取り付けた状態、左側=何も付けていない上シェル本体。

## 注意
- OP1 のこの構造は原理の参考であり、寸法・形状の丸写しはしない(他のマウスで再現できるようにするため)。
- 制作途中の他案件(ZA13 MOD 等)は参照しない。

## メイン基板の初期配置(自動配置の規則。オーナー確定 2026-10-11)
1. 向き: 基板の前(+y)をシェルの前へ。基板は反転しない(サイドスイッチだけ左利き用に反転)。
2. 高さ: アラウンドレンズの下面 = 底板の下面。
3. 左右(Y): センサー軸 = シェルの左右対称面(形から求めた対称面。bbox の中点ではない)。ずれるとマウスの動きがおかしくなる。左右非対称マウスの場合は、ユーザーと相談しながら位置を決める。
4. 前後(X): 保存済みセンサーマーカー(shell_report.json の sensor)を初期値とし、ホイール中心をシェルのホイール窓の中心に合わせて前に出す(前後は設計で変わるので厳密でなくてよい)。
5. メインクリック基板は左右2枚(1枚目の折り返しコピー)、サイドスイッチは左利き用に反転。

## ブッシュの標準位置（オーナー指示 2026-10-11）
ブッシュ先端の斜面は、底板と上部シェル（ミッドシェル）の外面とツライチにする。どのマウスでも標準。基板一式をX（前後）に動かして合わせる。OP1左手版では基板一式を後ろへ0.29mm動かして平均ギャップ約0mmにした。
