## 全体
- [確定] 2ピース: 上シェル + 底板。底板ネジ2本(後方、ケーブル付近)。
- [確定] 上シェル内: 全面アイソグリッド補強、真鍮インサート約6〜8本(円筒ポスト+根元に十字リブ、外周分散+スイッチ取付部)。
- [確定] 公称: 長119 / 高13-37 / 上幅 55.5(前)/55(中)/61(後) / 下幅 52/52/61 mm / 49.5g、ケーブル4mm径(ZH 5pin、後方出し)。

## PCB(底板に載る)
- [確定] 細長い1枚基板。前左にホイール/エンコーダ用の大きな切り欠き。後ろ右に細い張り出し(底面DPIボタン用)。
- [確定] センサー(PAW3950)は後方中央、コンパクトレンズ、底板の穴に合わせる。底板側にセンサー穴を囲む一段高い枠(PCB位置決め、[推定])。
- [確定] メイン2/サイド1のスイッチは別小基板(各ケーブル+白コネクタで本基板へ)。計6本の黒ネジで成形品のブリッジに固定。

## メインクリック
- [確定] ボタンは別部品: 板+長いカンチレバー腕。板裏にアイソグリッド、小枠に入った黒パッド、楕円ディンプル。腕根元は二股、先端にネジ穴(画像6,8)。
- [確定] シェル側に「Y字ブリッジ」2本(ネジ穴+位置決め小突起)。スイッチ小基板をここにネジ2本で固定(画像2,7)。
- [確定] クリック部の周囲に貫通スリット。ホイール窓は長方形穴、その両脇に腕/スイッチ取付部。
- [推定] 腕のしなりが戻りバネとストロークを作る。
- [不明] 画像6/8の板がどの窓に載る左右どの部品か。画像3/4の前方開口の用途。

## サイドボタン
- [確定] 前後2ボタンが1本の細い棒でつながる別部品。各ボタンは薄い脚+丸いピボット座。棒中央に切り欠き。シェル側壁に沿って装着(画像1,7)。
- [不明] 枠付き黒パッド(画像7)がサイドスイッチ当たり面か。

## 底板
- [確定] 全面アイソグリッド、中央センサー穴+隆起枠、後方にネジボス2、前側に背の高いブロック(用途不明: ホイール支え/ケーブルガイド[推定])。

## 汎用ルールとして抽出する原理(寸法は自前で実測・計算)
| 原理 | 汎用ルール |
|---|---|
| 薄壁+アイソグリッド | 薄壁でも剛性を出すリブ配置(密度/高さ/厚み) |
| ブリッジ+ネジ+ピン | スイッチ小基板は位置決めピン+ネジで成形品側に固定 |
| インサートポスト | ネジは肉厚+十字リブの円筒ポストで受ける |
| 腕のしなりで戻す | ストローク/戻り力は腕長・厚み・材料から計算 |
| ボタン機械分離 | 左右ボタン間にスリット、押し込みが干渉しない |
| センサー基準 | 原点=センサー光軸+底面。部品は保護体積として登録 |

## 設計の順序(案)
1 基準系(センサー) → 2 保護体積(PCB/スイッチ/エンコーダ/ホイール/ケーブル) → 3 中空化+空間余裕(壁1.2/1.5/2.0) → 4 底板・分割面・各穴 → 5 クリック機構 → 6 ホイール/サイドボタン → 7 固定(ボス/インサート/PCB押え/ケーブル抜け止め) → 8 剛性・製造 → 9 干渉検査・5役レビュー

## 製造条件(オーナー確定 2026-10-11)
- 機: QIDI Q2(FDM)。初期材料 ABS。最終は PPA-CF(今は考慮しない。ただし寸法は材料パラメータ化しておく)。
- 設計への含意(FDM): 最小壁は ノズル幅の整数倍(0.4mmノズルなら 1.2/1.6mm)、アイソグリッドはFDM向き、インサートは熱圧入(穴径は印刷収縮分を見込む)、
  オーバーハング45°以内/支持材を減らす分割、積層方向を部品ごとに決める(腕は板と同じ平面に寝かせて印刷=層間引張を避ける)、
  ボタン腕は肉厚と長さでばね定数を出し ABS で試作→ PPA-CF では脆いので別途見直し。
