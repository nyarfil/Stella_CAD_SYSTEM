# 別基板から得た汎用入力の学習

確認日: 2026-10-03。任意の基板・スキャンから新規マウスを作る目標を継続する。今回の工程は入力調査であり、新規の完成マウスCADを生成した記録ではない。

## 実形状の確認

- ZA13として登録された基板・底ケース・センサーSTEPを読み直した。基板の保存名とSTEPヘッダのR14名は異なり、版の来歴を未確定として扱う。
- 基板と底ケースは別々の座標照合を必要とする。穴配置のXY対応候補と、Z支持・実際の部品姿勢を分けて記録する。
- 基板STEPには板と部品形状がある。パックの空のswitchesを根拠に「スイッチ形状が存在しない」とは判定しない。押下軸・ストローク等の機能情報は未確定。
- 別のOP18系CADも読み直し、21ソリッドがBRep妥当性検査で有効だった。読込単位MMを確認した。部品役割や物理版の確認は別工程として残す。

測定記録: [ZA13座標照合](examples/za13_alternate_pcb_pose.json)、[OP18形状調査](examples/op18_alternate_hardware_intake.json)。元のCAD・登録パック・既存案件は変更していない。どちらも実スキャンの校正を検証したことにはならない。

ZA13の4軸対応を選んだ後のXY再計算では、回転約180度、移動約(-0.000913, -0.279523) mm、最大XY残差0.000530 mmだった。しかしZを変えない原座標診断では共通体積29.672099 mm³が残る。元のidentity配置でも12.464505 mm³が重なる。数値は原形状の診断であり、許容公差・支持高さ・物理受入の判定値ではない。

3点計算と4点目の照合を各点について行った結果は、対応選択にも再利用される。同じ4点による内部整合性の確認であり、最終姿勢の独立した受入検査ではない。今回の工具は4軸のパターンを探す限定プローブで、任意基板を自動認識する工具ではない。180度付近の角度を単純平均すると誤った90度になるため、最終姿勢は全対応点から剛体変換を再計算し、角度の平均を避けた。

## 図書館とStellaCADへの反映

作業ツリーの図書館JSONの共通契約を更新した。独立MCPの計画と知識取得、StellaCADブリッジから同じ記述を参照できる。

1. readyは保存状態。対象の基板と外装の組合せについて、ハッシュ・版・配置・機能を別途確認する。
2. 無干渉だけで正しい配置とはしない。穴が一致していても支持高さや部品が成立しないことがある。
3. 部品形状の存在と、作動に必要な機能情報の存在を分ける。
4. センサーの外接箱とケースの最下点の差を光学距離として認定しない。

更新後に既存の受入試験21件を実行して成功した。汎用計画に上記の条件が返ることを追加確認した。これはMCP返却・連携の確認であり、マウスの製造・操作・光学性能の証明ではない。既存0.1.4配布ZIP/wheelは保存時の内容を保持しており、この作業ツリー更新は未収録。

## 次に成立させる条件

対象基板を選ぶ工程では、穴対応だけでなく支持面・高さ・光学基準・コネクタ方向を照合する。機構の作動量や組立経路を定義したうえで、独立案件に実CADを生成し、干渉・動作・製造を検査する。スキャンについては入力の縮尺・欠損・元形状の役割を別に確認する。今回の測定だけで汎用設計能力を完成としない。
