# ZS-F1 / G305：取り付け基準と可動部の測定記録

確認日: 2026-10-03。これは参考形状の照合記録であり、実物適合・印刷・動作の合格記録ではない。
基本の部品分解と出典は [参照ノート](REFERENCE_ZS_F1_G305_MOUSE_JA.md) を参照する。

## 主クリック板の位置合わせ

[円境界測定](examples/zs_f1_g305_planar_boundaries.json)から、上ケースの左右中心 `X=±13.35821, Y=-1.82447, Z=27.16858` とクリック板の左右中心 `X=±13.35821, Y=-44.68227, Z=-48.52872` を照合した。

クリック板をX軸まわりに+90°回転し `[0, -50.35318797, 71.85085869]` を加えると、中心残差は最大約1.7e-7座標単位。[姿勢候補JSON](examples/zs_f1_g305_click_mounting_pose.json)に入力ハッシュ、変換、仮定を記録した。これは選択した中心の数値一致であり、実物の組立精度ではない。クリック板の下側の固定面を上ケースの支持面へ直接置く仮定を含む。

この候補では裏の調整穴中心は `X=±17.29897, Y=-33.94867`。固定穴中心との長手方向の距離は約32.1242だが、実際の曲げ支点が未確定なので有効レバー長とは呼ばない。スイッチとの隙間、予圧、押下量、停止位置、復帰は未検証。

## 追加のG305基板参考STEP

[g305-reのCAD](https://github.com/you-wouldnt-reverse-engineer-a-rat/g305-re/tree/main/cad)にある `G305_PCB.step` を取得し、cadgenとClassCADで読んだ。公開元はinornateへクレジットを記す。ユーザー提供一式には含まれない追加資料で、Logitech公式図面や手元個体の正本ではない。

SHA-256: `efd955a61c99290ab946f075e769cd0279802535fc72e52697031d0c41635028`。STEPはmmの長さ単位を宣言し、ヘッダーは2019-05-24生成と記す。参考アセンブリは11ソリッド、外接寸法45.55 × 91.04766 × 19.81498 mm。原形状は一時参照ファイルとして保持し、リポジトリには転載していない。

ClassCADで空のローカルセッションを確認後に読込み、`Mainboard`, `LED`, `Encoder`, `Wheel switch`, `DPI switch`, `Sensor`, `Conn_Mainbtn`, `Conn_SideBtn`, `Conn_battery`, `Lens`, `Body11` のソリッド名を確認した。名前はCAD作者の分類で、実物型番の保証ではない。左右主スイッチ、サイドボタン基板、ホイールそのものの独立ラベルはなく、全搭載部品がそろったとは扱わない。

[形状別測定JSON](examples/zs_f1_g305_board_reference_measurements.json)のBRep参照は上記ハッシュに限定される。`#o1.s1` は45.55 × 91.04766 × 0.8 mmの薄い基板形状。他のソリッドの並び順から部品名を推定していない。

## 丸穴と開放溝は違う

基板形状には半径1.45 mmの固定用候補境界が4箇所あるが、**閉じた円が2箇所、半円状の開放溝が2箇所**だった。円弧の中心が分かっても全円の穴とは限らない。溝の挿入方向は、周囲の直線境界と実組立手順で追加確認する。

底ケースのZ=5.15976にある半径0.65の円境界4箇所を、ねじ軸の候補として照合した。4箇所の円/円弧中心を等しい重みで剛体比較すると、Z軸まわり179.79635°回転、移動 `[0.05737922, -4.58117797, 5.15975666]` が最小残差の対応になる。

| 指標 | 結果（STL座標単位） |
|---|---:|
| 4箇所のXY中心ずれ | 0.23046 / 0.10963 / 0.06323 / 0.12291 |
| RMS中心ずれ | 0.14512 |
| 最大中心ずれ | 0.23046 |
| 24通りの対応で次点のRMS | 8.32369 |

有力な対応候補だが精密一致ではない。STEPの1 mmをSTLの1座標単位と扱う比較上の仮定と、基板下面をねじボス上面へ置く仮定がある。部品を拡縮して残差を消していない。記録は[基板姿勢JSON](examples/zs_f1_g305_board_mounting_pose.json)、再現は[位置合わせスクリプト](../integration/mouse_reference/align_board_reference.py)。底ケースと基板の重ね合わせ画像も確認した。

底部の内側の穴半径0.65を、ねじ軸半径や位置決めピン外径として流用しない。ねじ外径・頭の座面・締結後の位置決めは別の検討項目。未知のねじ径を使って残差を許容内と判定しない。

この姿勢で参考アセンブリの最下端は底ケース原点面より約0.36420上。ただし幾何的な最下端は、光学焦点面やセンサー作動距離ではない。光学面、フィート厚さ、接着層、荷重による変形と机面の位置が別途必要になる。

## StellaCADへ適用する設計条件

- PCB固定を、上下支持、XY位置決め、ねじによる保持、挿入・取り外し経路の4役割に分ける。
- 開放溝を閉じた穴へ置き換えると、元の差し込み経路を失う可能性を確認する。
- ボタンでは指接触面、固定部、可動/柔軟部、スイッチ接触部、反力を受ける支持部、復帰、停止部を分ける。
- 光学高さは机面を基準にレンズ・基板・ボス・底板・フィートを関連付ける。
- ホイール軸はエンコーダ軸と反対側支持部を同じ配置で管理する。
- 参考CADの非ゼロ残差を保持し、ZA13用ハードウェアや任意の箱形部品でG305適合を代替しない。
- 静止画像や形状の有効性だけでは、クリック復帰、ホイール操作、光学追従を合格にしない。

## ホイール：回転と中央クリックを別に設計する

2026-10-03に[G305ホイール交換ガイド](https://www.ifixit.com/Guide/Logitech+G305+Scroll+Wheel+Replacement/148616)のStep 5とStep 7の実物写真をブラウザーで確認した。Step 5本文は片側を金属ばねが保持すると説明し、写真には軸付近の保持部がある。Step 7写真ではホイールの両側へ軸が延び、片側が基板上の検出部へ接続する構成が見える。本文は右へ滑らせて取り外す手順を記す。右は写真・組立姿勢に依存し、StellaCADの絶対X方向には変換しない。

参考STEPでは `Encoder` と `Wheel switch` が独立したソリッドとして存在し、ClassCADで両方を強調表示した。ホイール本体は含まれない。写真と参考CADが手元個体・提供STLと同一仕様である保証はない。

| 機能 | 設計で記録する条件 | 現在の証拠の限界 |
|---|---|---|
| 回転 | ホイール軸とエンコーダの接続形状、回転軸、軸方向保持、回転中の外装との隙間 | 接続形状の寸法・嵌合、公差、ホイール外径は未測定 |
| 中央クリック | ホイールからスイッチへの力の経路、動く軸端、押下量、復帰、停止位置 | 押下中の写真・変位測定がなく、軸の傾きと移動量は未確定 |
| 支持と保持 | エンコーダ側、反対側支持、ばねの固定と取り外し経路 | ばねの保持役割はガイドに根拠があるが、復帰力・回転の段階感への寄与は未確定 |
| 組立 | 軸を接続する方向、ばねを装着する順番、工具と指のアクセス | 純正分解手順をZS-F1の組立手順としてそのまま流用できない |

軸の両端を動かない閉じた穴へ固定すると、回転はできても中央クリックの動きを妨げる可能性がある。一方、ホイール全体を垂直移動させる単純モデルも、エンコーダ側の接続がそれを許すと確認できるまで採用しない。回転角と押下変位を別の状態変数として記録し、無操作・回転・中央クリック押下・復帰の状態で接続と隙間を確認する。

これは機構の要求整理であり、動作検証済みのホイール機構ではない。次の測定対象はホイール軸端、エンコーダ接続面、反対側支持形状、中央クリック接触部、ばね固定部である。

## 主クリック板の鉛直材料区間

`measure_click_chords.py` で、候補姿勢の `X=±13, ±15, ±17.3` と14箇所のY位置を測定した。84点中80点が偶数交点の候補、4点が交差なし、奇数交点は0。報告は [鉛直区間JSON](examples/zs_f1_g305_click_chords.json)。原STL、姿勢レポート、測定スクリプトのハッシュを記録する。

| サンプル（候補姿勢） | Z方向の材料区間の長さ | 読み取りの限界 |
|---|---:|---|
| X=13, Y=0 | 約1.30000 | 取り付け付近の局所区間。法線肉厚や曲げ長さとは呼ばない。 |
| X=13, Y=-6 | 約8.73973 | 上下の形状を通る長い区間。薄板の肉厚には使わない。 |
| X=13, Y=-4 | 約1.75000と約1.44546の2区間 | その線に離れた材料区間がある。別部品や特定機能の証明ではない。 |
| X=13, Y=-2 | 交差なし | 取付穴候補付近だが、全体の断裂や可動隙間を示すものではない。 |

単位は未確定のSTL座標単位。閉じた自己交差のない材料境界を仮定し、鉛直交点を重複除去して対にしている。辺・頂点や接線上のサンプルは曖昧になり得る。偶数交点が取れたことはメッシュの自己交差不存在や固体としての妥当性を証明しない。

曲がったクリック面では、鉛直方向の距離と板面に垂直な肉厚が異なる。リブ・段差・接触ボスを横切る値も含まれるため、これを曲げ剛性、クリック荷重、疲労の式へ入れない。次は機能部の分類、法線方向の肉厚、固定・接触境界、材料と層方向を確認する。図書館0.1.1にはこの制約と測定レポートを収録する。

## 主クリック板の表面法線方向の区間

`measure_click_normal_chords.py` は、同じ84点の最上面で頂点から三角形法線を計算し、幾何的に上向きへ揃え、その反対方向の最初の交点までを測る。65点が局所的に平行な面の候補、15点が非平行の交差、4点は最上面への交差なし。平行候補の閾値10度は分類上の選択であり、製造公差ではない。全サンプルを [法線方向区間JSON](examples/zs_f1_g305_click_normal_chords.json) に記録する。

| X=13のサンプル | 鉛直区間 | 表面法線方向の区間 | 解釈 |
|---|---:|---:|---|
| Y=-10 | 1.82505 | 1.75791 | 局所的に平行な面の候補 |
| Y=-26 | 1.96981 | 1.76124 | 局所的に平行な面の候補 |
| Y=-50 | 2.13982 | 1.76375 | 局所的に平行な面の候補 |
| Y=-6 | 8.73973 | 8.99130 | 非平行の交差。薄板の肉厚として使わない |

単位は未確定のSTL座標単位。上の3点では鉛直距離が増えても法線方向の区間は約1.76で近い。したがって鉛直距離だけを見て前方ほど板が厚くなると結論してはいけない。これは選んだ3点の比較であり、板全体の均一肉厚の証明ではない。

独立レビューでは別の交差計算で代表6点の距離・面番号・法線の内積が一致した。今回の80出口すべてで開始面と出口面の生法線は逆向き。最終スクリプトでは符号付き内積も記録し、同方向の面を平行対向面の候補から除外する。これはメッシュ全体の向きの検証ではない。

最上面の法線から投射する方法は、最小肉厚や対向面への最短距離を求める方法とは異なる。上向きへ法線を揃える操作も、全メッシュの向き・自己交差不存在・内部外部を検証しない。段差、補強、離れた材料、接線や辺・頂点付近には追加確認が必要になる。約1.76をクリック剛性・疲労の式へ直接流用しない。

この追加レポートは参照解析として保存し、配布済みの図書館0.1.1には未収録。図書館の収録内容とローカルの追加解析を区別する。
