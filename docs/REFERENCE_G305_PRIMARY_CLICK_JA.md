## スイッチ仕様の探索で分かった制約

[iFixitの実物交換ガイド](https://www.ifixit.com/Guide/Logitech+G305+Lightspeed+Mouse+Switch+Replacement/206824) Step 7/8は、4本のねじを外し、スイッチを載せた2つの小基板を取り出す手順を示す。スイッチをケースへ直接固定する構造とは区別する。

[メーカーのD2FCページ](https://www.aratas.com/jp-ja/products/switches/D2FC) は20M/60M/100M等を掲載し、CADはログインが必要と説明する。旧10M版を今回の参考形状やユーザー個体へ対応付けるメーカー根拠は得られていない。検索に出る別版の寸法・操作力・PTを旧10M版へ転用しない。メーカーPDFの直接取得はAccess Denied、ブラウザー表示も本文を確認できなかったため、検索抜粋を確定仕様として収録しない。

PT（作動までの動き）、MD（作動と復帰の位置差）、OT（作動後の余裕）、FP/OP（基準面からの位置）を区別する。OTの「最小保証」を、スイッチを壊さず押し込める最大値へ読み替えない。クリック板の指面の動きと、プランジャの動きも同じ値ではない。

## 原理案の比較

以下は新しい機構の案であり、ZS-F1の実機構を認定するものではない。

| 案 | 戻る力 | 主な設計課題 |
|---|---|---|
| 上ケース一体の曲げ舌 | 舌の弾性。接触中はスイッチも補助 | 握り荷重との連成、根元応力、層方向、クリープ、疲労 |
| 独立した対称フレクシャキャリア | 複数梁の弾性 | ねじれと横滑り、梁のばらつき、過拘束、疲労 |
| ピン軸レバー＋独立ばね | 別の板ばね・ねじりばね | 軸受ガタ・摩擦・同軸度、抜け止め、接触の横滑り、組立 |

機構の原理実証には、運動・復帰・停止・高さ調整を個別に測れるピン軸案が候補。ただし重さ・部品数・スペースと実物仕様を照合してから製品案を選ぶ。単純さやCAD生成容易性だけで最終案を決めない。

## 固定、荷重、復帰、停止

スイッチ支持、軸受、上下ストッパーを同じ基準フレームへ結ぶ。接触高さの調整ねじは、支点固定や下側ストッパーと兼用しない。追加荷重をスイッチへ流し続けないよう、接触子付近に専用停止ランドを設ける。停止後のフレーム・基板・ストッパーの変形も押込み量へ含める。

1. 無操作: ばね→クリック板→上側ストッパー→フレーム。左右ともOFF。
2. 作動: 指→クリック板→接触子→スイッチ→小基板支持→フレーム。軸受とばね座にも反力。
3. 最大押下: 追加荷重→クリック板→下側ストッパー→フレーム。スイッチの許容押込みを超えない。
4. 復帰: OFF閾値を通過してからも、独立ばねが上側停止位置へ戻す。

正の隙間がある場合、スイッチとの接触が切れるとスイッチからの復帰力も失われる。完全復帰に必要な力をクリック板または独立ばねが供給するか確認する。

## StellaCADへ渡す状態条件

`u(q,F)` はスイッチハウジングに対する接触子のプランジャ方向移動。回転、接触点移動、指定荷重での支持部のたわみを含む。`g` は休止時の符号付き隙間（正=空隙）。押込みは `δ=max(0,u−g)`。

```text
休止後OFF: δ_rest,max ≤ δ_off,min − m_release
停止前ON: max(0,u_pre_stop,min−g_max) ≥ δ_on,max + m_on
過押込み防止: max(0,u_post_stop,max(F_design)−g_min) ≤ δ_allow,min − m_safe
全行程の復帰（0<q≤q_stop）: Q_return,min(q) > Q_friction,max(q)+Q_adverse,max(q)
他側の誤作動防止: δ_other,max < δ_on,other,min − m_crosstalk
準静的な力の釣合い: F_finger·du_f/dq = F_switch·dδ/dq + Q_return + Q_loss (+ Q_stop)
```

`u_pre_stop,min` は下側停止部へ触れる直前の最小閉鎖量。`u_post_stop,max(F_design)` は停止後、設計最大荷重で基板・フレーム・停止部のたわみを含む最大閉鎖量。両者を同じ状態として評価しない。

`du_f/dq` と `dδ/dq` は実際の運動から求める変位の比で、参考STLの穴中心間距離ではない。`Q` はqに対応する一般化力。停止後は停止反力、q=0では上側停止反力も含める。スイッチの復帰力はδ>0の接触中だけ有効。動的な衝撃はこの準静的な式で検証したことにしない。

閾値・許容押込み・余裕・荷重は未確定。成立条件を式にできたことは成立の証明ではない。摩擦、横荷重、調整の緩み、組立経路、製造公差、寿命を別途確認する。Stellaの直線移動検査を回転や弾性変形の検査として使わない。
